# 📦 ArchGen

A simple and flexible CLI tool for generating clean, scalable project architectures.

`archgen` helps developers quickly scaffold projects using common patterns like **MVC**, **MVVM**, or **Clean Architecture**, so you can focus on building features instead of structuring folders.

---

## ✨ Features

- ⚡ Generate project structures instantly
- 🧱 Supports multiple architecture patterns:
  - MVC
  - MVVM
  - Clean Architecture
  - Custom templates
- 🛠️ Lightweight and easy to extend
- 📁 Consistent, production-ready folder layouts
- 🔧 CLI-based workflow
